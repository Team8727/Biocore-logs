# Sample data

`synthetic.wpilog` is a deterministic fixture generated by
`tools/power-parser/src/test/java/org/biocore/power/SyntheticLog.java`. It is
not a real match.

The demo report in `data/sessions/` is generated from this fixture so the site
can be previewed without a robot. Before publishing real logs, delete the demo
session files and the matching entry in `data/processed.json`, then rebuild the
index:

```bash
rm -f data/sessions/<demo-session-id>.*
# remove the demo SHA-256 entry from data/processed.json
JAVA_HOME="$HOME/wpilib/2026/jdk" \
  tools/power-parser/build/install/power-parser/bin/power-parser \
  --index-only \
  --output-dir data
```

`--index-only` rebuilds `data/index.json` from the remaining session files.
